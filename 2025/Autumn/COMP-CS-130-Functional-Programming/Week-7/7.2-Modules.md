## What are Modules?

**A Haskell module** is a collection of related [functions](../Week-2/2.2-First-Haskell-Functions.md), [types, and typeclasses](../Week-3/3.1-Types-and-Typeclasses.md). A Haskell program consists of modules where the main module loads others and uses their functions.

**Benefits of modules:**
- Code reusability across different programs
- Better organization through separation of concerns
- Easier maintenance with loosely coupled components
- Generic modules can be used in multiple projects

## Importing Modules

### Basic Import Syntax
```haskell
import Data.List
```

**Rules:**
- Import statements must come **before any function definitions**
- Usually placed at the **top of the file**
- Each import on a separate line

**Example:**
```haskell
import Data.List

numUniques :: (Eq a) => [a] -> Int
numUniques = length . nub
```

`nub` removes duplicate elements from a list. It's defined in `Data.List` and becomes available after import.

### Importing in GHCi
```haskell
ghci> :m + Data.List                    -- Load single module
ghci> :m + Data.List Data.Map Data.Set  -- Load multiple modules
```

**Note:** If your script already imports a module, you don't need `:m +` in GHCi.

## Selective Imports

### Import Specific Functions
```haskell
import Data.List (nub, sort)  -- Only import nub and sort
```

### Import Everything Except
```haskell
import Data.List hiding (nub)  -- Import all except nub
```

**Use case:** When you have your own function with the same name and want to avoid conflicts.

## Qualified Imports

### Problem: Name Clashes

Modules like `Data.Map` export functions with the same names as `Prelude` (e.g., `filter`, `null`).

### Solution 1: Qualified Import
```haskell
import qualified Data.Map

-- Now must use full name:
Data.Map.filter  -- Data.Map's filter
filter           -- Prelude's filter
```

### Solution 2: Qualified with Alias
```haskell
import qualified Data.Map as M

-- Shorter prefix:
M.filter    -- Data.Map's filter
filter      -- Prelude's filter
```

**Recommended approach** for modules with common function names!

## Standard Library & Resources

### Haskell Standard Library
**Reference:** [GHC Libraries Documentation](https://downloads.haskell.org/~ghc/latest/docs/html/libraries/)

The standard library is organized into modules:
- List manipulation
- Concurrent programming
- Complex numbers
- Data structures (Map, Set, etc.)
- And many more...

### Hoogle - Function Search
**Website:** [hoogle.haskell.org](https://hoogle.haskell.org/)

Search by:
- Function name
- Module name
- **Type signature** (very powerful!)

**Example searches:**
- `nub` - find the function
- `[a] -> [a]` - find all functions with this signature
- `Data.List` - browse all functions in module

## Learning Tips

1. **Browse the standard library** - click through modules to discover functions
2. **Read source code** - viewing module implementations is great for learning
3. **Use Hoogle** - when you know what you want but not the function name
4. **Check type signatures** - they tell you exactly what a function does

## Common Import Patterns
```haskell
-- Basic imports
import Data.List
import Data.Char

-- Selective import
import Data.List (sort, nub)

-- Hiding functions
import Data.List hiding (insert)

-- Qualified with alias
import qualified Data.Map as Map
import qualified Data.Set as Set

-- Combining techniques
import Data.List (nub)
import qualified Data.Map as M
```

## Remember

- **Prelude** is imported by default (contains basic functions)
- Import statements go at the **top of the file**
- Use **qualified imports** to avoid name conflicts
- **Aliases** make qualified imports less verbose
- Reading standard library source code improves Haskell skills
