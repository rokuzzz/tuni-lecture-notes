The `Data.Char` module exports functions for working with characters. Very useful for filtering and mapping over strings (since strings are lists of characters).

**Import:** `import Data.Char`

---

## Character Predicates

All predicates have type `Char -> Bool` - they test if a character satisfies some condition.

### Basic Type Checks
```haskell
isControl      -- control character
isSpace        -- whitespace (space, tab, newline, etc.)
isPrint        -- printable character
```

### Letter & Number Checks
```haskell
isLower        -- lowercase letter
isUpper        -- uppercase letter
isAlpha        -- letter
isAlphaNum     -- letter or number
isDigit        -- digit (0-9)
isOctDigit     -- octal digit (0-7)
isHexDigit     -- hex digit (0-9, a-f, A-F)
isLetter       -- letter
isNumber       -- numeric character
```

### Special Character Checks
```haskell
isPunctuation  -- punctuation
isSymbol       -- mathematical or currency symbol
isSeparator    -- Unicode spaces and separators
isMark         -- Unicode mark characters (accents, etc.)
```

### Unicode Range Checks
```haskell
isAscii        -- first 128 characters of Unicode
isLatin1       -- first 256 characters of Unicode
isAsciiUpper   -- ASCII and uppercase
isAsciiLower   -- ASCII and lowercase
```

## Practical Examples

### Validate Username
```haskell
all isAlphaNum "bobby283"        -- True
all isAlphaNum "eddy the fish!"  -- False
```

### Custom Word Splitting
```haskell
-- Group by spaces, then filter out space groups:
filter (not . any isSpace) . groupBy ((==) `on` isSpace) $ "hey folks its me"
-- ["hey","folks","its","me"]
```

## General Category

**`generalCategory`** returns the Unicode category of a character:
```haskell
generalCategory :: Char -> GeneralCategory

generalCategory ' '   -- Space
generalCategory 'A'   -- UppercaseLetter
generalCategory 'a'   -- LowercaseLetter
generalCategory '.'   -- OtherPunctuation
generalCategory '9'   -- DecimalNumber

map generalCategory " \t\nA9?|"
-- [Space,Control,Control,UppercaseLetter,DecimalNumber,OtherPunctuation,MathSymbol]
```

**Note:** `GeneralCategory` is part of `Eq` typeclass, so you can test: `generalCategory c == Space`

## Case Conversion
```haskell
toUpper 'a'    -- 'A'
toLower 'A'    -- 'a'
toTitle 'a'    -- 'A' (for most characters, same as upper-case)
```

Spaces, numbers remain unchanged.

## Character ↔ Number Conversion

### Digit Conversions

**`digitToInt`** - convert character to Int (0-9, a-f, A-F):
```haskell
map digitToInt "34538"    -- [3,4,5,3,8]
map digitToInt "FF85AB"   -- [15,15,8,5,10,11]
```

**`intToDigit`** - convert Int (0-15) to character:
```haskell
intToDigit 15  -- 'f'
intToDigit 5   -- '5'
```

### Unicode Value Conversions

**`ord`** - character to Unicode number:
```haskell
ord 'a'           -- 97
map ord "abcdefgh"  -- [97,98,99,100,101,102,103,104]
```

**`chr`** - Unicode number to character:
```haskell
chr 97  -- 'a'
```

**Useful fact:** The difference between `ord` values equals distance in Unicode table.

## Practical Example: Caesar Cipher

**Encoding** - shift each character by fixed number:
```haskell
encode :: Int -> String -> String
encode shift msg = 
    let ords = map ord msg
        shifted = map (+ shift) ords
    in  map chr shifted

-- Or with composition:
encode shift msg = map (chr . (+ shift) . ord) msg
```

**Examples:**
```haskell
encode 3 "Heeeeey"                    -- "Khhhhh|"
encode 5 "Marry Christmas! Ho ho ho!" -- "Rfww~%Hmwnxyrfx&%Mt%mt%mt&"
encode 1 "abcd"                       -- "bcde"
```

**Decoding** - shift back:
```haskell
decode :: Int -> String -> String
decode shift msg = encode (negate shift) msg
```

**Examples:**
```haskell
encode 3 "Im a little teapot"         -- "Lp#d#olwwoh#whdsrw"
decode 3 "Lp#d#olwwoh#whdsrw"         -- "Im a little teapot"
decode 5 . encode 5 $ "This is a sentence"  -- "This is a sentence"
```

## Common Patterns

### Filter alphanumeric only:
```haskell
filter isAlphaNum "hello123!@#"  -- "hello123"
```

### Convert to uppercase:
```haskell
map toUpper "hello world"  -- "HELLO WORLD"
```

### Check if all letters:
```haskell
all isAlpha "HelloWorld"   -- True
all isAlpha "Hello World"  -- False (space!)
```

### Remove non-digits:
```haskell
filter isDigit "abc123def456"  -- "123456"
```

## Remember

- Strings are lists of characters - all list functions work!
- Predicates return `Bool` - great for `filter`, `all`, `any`
- `ord` and `chr` let you do arithmetic on characters
- Combine with `Data.List` functions for powerful text processing
