## Basic Arithmetic

Haskell handles basic math operations exactly as you'd expect. All usual precedence rules apply, and parentheses work for grouping operations.
```haskell
ghci> 2 + 15
17
ghci> 49 * 100
4900
ghci> 5 / 2
2.5
ghci> (50 * 100) - 4999
1
ghci> 50 * (100 - 4999)
-244950
```

**Important:** Always wrap negative numbers in parentheses: `5 * (-3)` works, `5 * -3` doesn't.

## Boolean Operations

Standard boolean operators work as expected:

- `&&` - boolean AND
- `||` - boolean OR
- `not` - negation
- `==` - equality
- `/=` - inequality (not equal)
```haskell
ghci> True && False
False
ghci> not (True && True)
False
ghci> 5 /= 4
True
ghci> "hello" == "hello"
True
```

## Type System Basics

Haskell has a strict type system. You can't mix incompatible types:
```haskell
ghci> 5 + "llama"
-- ERROR: No instance for (Num String)

ghci> True == 5
-- ERROR: Types don't match
```

**Key rule:** Operations work only on compatible types. The `+` operator expects numbers, `==` can compare any two things of the same type.

**Exception:** `5 + 4.0` works because `5` can act as either integer or floating-point, so it adapts to match `4.0`.

## Functions in Haskell

### Function Application Syntax

1. **Prefix functions (most common):** `functionName parameter1 parameter2`
2. **Infix functions:** Operators like `+`, `*`, `/` go between their arguments
```haskell
ghci> succ 8          -- successor function
9
ghci> min 9 10        -- minimum of two numbers
9
ghci> max 100 101     -- maximum of two numbers
101
```

### Function Precedence

Function application has the **highest precedence** of all operations:
```haskell
ghci> succ 9 + max 5 4 + 1
16
-- Same as: (succ 9) + (max 5 4) + 1
```

To get successor of a product: `succ (9 * 10)` gives 91, not `succ 9 * 10` which gives 100.

## Infix vs Prefix

Any two-parameter function can be used as infix by wrapping in backticks:
```haskell
ghci> div 92 10       -- prefix style
9
ghci> 92 `div` 10     -- infix style (clearer)
9
```

## Important Syntax Notes

**No parentheses for function calls:** In C you write `foo()`, `bar(1)`, in Haskell it's `foo`, `bar 1`.

**Nested calls:** `bar (bar 3)` means "call bar with 3, then call bar with that result" - equivalent to C's `bar(bar(3))`.

### Key Differences from Imperative Languages

- Functions called with spaces, not parentheses
- Function application has highest precedence
- Strict type system prevents many runtime errors
- All values are immutable
