## Function Definition Syntax

Functions in Haskell are defined similarly to how they're called. The pattern is:
```haskell
functionName parameter1 parameter2 = expression
```

**Basic example:**
```haskell
doubleMe x = x + x
```

## Working with Functions

### Loading and Testing Functions

1. Write functions in a **.hs** file (e.g., `baby.hs`)
2. Navigate to the file's directory in terminal
3. Start `ghci` from that directory
4. Load your file: `:l baby`
5. Test your functions
```haskell
ghci> :l baby
[1 of 1] Compiling Main ( baby.hs, interpreted )
Ok, one module loaded.
ghci> doubleMe 9
18
ghci> doubleMe 8.3
16.6
```

### Multiple Parameters

Functions can take multiple parameters, separated by spaces:
```haskell
doubleUs x y = x*2 + y*2
-- Alternative definition:
doubleUs x y = x + x + y + y
```

### Function Composition

You can call your own functions from other functions. This promotes code reuse and clarity:
```haskell
doubleUs x y = doubleMe x + doubleMe y
```

**Key principle:** Build complex functions from simple, obviously correct functions. This avoids repetition and makes code more maintainable.

## Conditional Logic: if-then-else

Haskell's if statement is different from imperative languages:
```haskell
doubleSmallNumber x = if x > 100
                      then x
                      else x*2
```

**Important differences:**

- The `else` part is **mandatory** in Haskell
- `if-then-else` is an **expression** (always returns a value)
- Can be written on one line or multiple lines for readability

### Using if-then-else in Expressions

Since if-then-else is an expression, you can use it anywhere you need a value:
```haskell
doubleSmallNumber' x = (if x > 100 then x else x*2) + 1
```

**Note:** Parentheses matter! Without them, the `+ 1` would only apply to the else branch.

## Functions Without Parameters

Functions that take no parameters are called **definitions** or **names**:
```haskell
conanO'Brien = "It's a-me, Conan O'Brien!"
```

Once defined, the name and its value are interchangeable throughout your program.

### Naming Rules and Conventions

#### Function naming rules:

- Must start with a **lowercase letter**
- Can contain letters, numbers, underscores, and apostrophes (`'`)

#### The apostrophe (`'`) convention:

- Often used for strict versions of functions
- Used for slightly modified versions of functions/variables
- Valid character in function names: `doubleSmallNumber'`

## Key Concepts

**Function Order:** Functions can be defined in any order in your file. Haskell doesn't require forward declarations.

**Everything Returns Something:** In Haskell, every expression and function must return a value. This is why `else` is mandatory in `if` statements.

**Expressions vs Statements:** Haskell uses expressions (things that return values) rather than statements (commands that do things).
