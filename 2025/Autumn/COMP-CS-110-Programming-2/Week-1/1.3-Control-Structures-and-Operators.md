## Guessing Game Example

Programming concepts are language-independent! The logic of if statements, while loops, and conditions remains the same across languages.

### TypeScript Version
```typescript
import * as readline from 'readline';

const rl = readline.createInterface({
    input: process.stdin,
    output: process.stdout
});

function main(): void {
    rl.question("Input a secret number: ", (secretInput: string) => {
        const secret_number: number = parseInt(secretInput);
        let guessed_number: number = -1;
        let guesses: number = 0;
        
        function makeGuess(): void {
            if (secret_number !== guessed_number) {
                rl.question("Give a guess: ", (guessInput: string) => {
                    guessed_number = parseInt(guessInput);
                    guesses += 1;
                    
                    if (guessed_number < secret_number) {
                        console.log("Your guess is too small!");
                    } else if (guessed_number > secret_number) {
                        console.log("Your guess is too great!");
                    } else {
                        console.log("Correct!");
                    }
                    
                    makeGuess(); // Recursive call to continue
                });
            } else {
                console.log("Number of guesses:", guesses);
                rl.close();
            }
        }
        
        makeGuess();
    });
}

main();
```

### C++ Version
```cpp
#include <iostream>
using namespace std;

int main() {
    int secret_number = 0;
    cout << "Input a secret number: ";
    cin >> secret_number;
    
    int guessed_number = -1;
    int guesses = 0;
    
    while (secret_number != guessed_number) {
        cout << "Give a guess: ";
        cin >> guessed_number;
        guesses += 1;
        
        if (guessed_number < secret_number) {
            cout << "Your guess is too small!" << endl;
        } else if (guessed_number > secret_number) {
            cout << "Your guess is too great!" << endl;
        } else {
            cout << "Correct!" << endl;
        }
    }
    
    cout << "Number of guesses: " << guesses << endl;
}
```

## Curly Braces Rules

### Safe Approach (Recommended)
```cpp
// ✅ Always use braces - safe and clear
while (i < 10) {
    ++i;
}
cout << i << endl;
```

### Dangerous Approach (Avoid)
```cpp
// ⚠️ Can omit braces for single statement, but risky!
while (i < 10)
    ++i;
cout << i << endl;  // This is NOT part of the loop!
```

### Why Braces Matter
```cpp
// ❌ DANGEROUS - looks like both statements are in loop
int i = 0;
while (i < 10)
    ++i;
    cout << i << endl;  // This executes only ONCE after loop ends!
cout << "Job continues after the loop" << endl;
```

**What actually happens:**
- Only `++i;` is inside the loop
- `cout << i << endl;` executes once after the loop finishes
- This creates hard-to-find bugs!

### Brace Placement Styles

**Style 1 (Compact):**
```cpp
if (x) {
    // code here
}
```

**Style 2 (Aligned):**
```cpp
if (x)
{
    // code here
}
```

**Rule:** Pick one style and be consistent throughout your program!

## For Loop Comparison

### C++ For Loop
```cpp
for (int number = 5; number < 10; ++number) {
    cout << 9 * number << endl;
}
```

### TypeScript Equivalent
```typescript
for (let number = 5; number < 10; number++) {
    console.log(9 * number);
}

// Alternative range-like approach:
for (let number of Array.from({length: 5}, (_, i) => i + 5)) {
    console.log(9 * number);
}
```

## Loop Control Statements

### Break Statement
```cpp
break;  // Terminates the loop immediately
```

**Example:**
```cpp
for (int i = 0; i < 10; i++) {
    if (i == 5) {
        break;  // Loop stops when i reaches 5
    }
    cout << i << endl;  // Prints: 0, 1, 2, 3, 4
}
```

### Continue Statement
```cpp
continue;  // Skips rest of loop body, jumps to next iteration
```

**Example:**
```cpp
for (int i = 0; i < 10; i++) {
    if (i % 2 == 0) {
        continue;  // Skip even numbers
    }
    cout << i << endl;  // Prints: 1, 3, 5, 7, 9
}
```

### Return Statement
```cpp
return;  // Exits the entire function (and any loops inside it)
```

**Note:** For functions with return values, you must return a value: `return value;`

## C++ Operators

### Relational Operators

| Operator | Meaning              | Example      |
|----------|----------------------|--------------|
| `==`     | Equal to             | `a == b`     |
| `!=`     | Not equal to         | `a != b`     |
| `<`      | Less than            | `a < b`      |
| `>`      | Greater than         | `a > b`      |
| `<=`     | Less than or equal   | `a <= b`     |
| `>=`     | Greater than or equal| `a >= b`     |

### Assignment Operators

| Operator | Meaning                    | Example        | Equivalent    |
|----------|----------------------------|----------------|---------------|
| `=`      | Assignment                 | `a = 5`        | `a = 5`       |
| `+=`     | Add and assign             | `a += 3`       | `a = a + 3`   |
| `-=`     | Subtract and assign        | `a -= 3`       | `a = a - 3`   |
| `*=`     | Multiply and assign        | `a *= 3`       | `a = a * 3`   |
| `/=`     | Divide and assign          | `a /= 3`       | `a = a / 3`   |
| `%=`     | Modulo and assign          | `a %= 3`       | `a = a % 3`   |

### Increment/Decrement Operators
```cpp
++i;  // Increment i by 1
--i;  // Decrement i by 1

// Also works with post-increment/decrement:
i++;  // Increment i by 1 (after using current value)
i--;  // Decrement i by 1 (after using current value)
```

**Safety tip:** Use these operators alone in a statement to avoid unexpected behavior.

### Arithmetic Operators

| Operator | Meaning        | Example   |
|----------|----------------|-----------|
| `+`      | Addition       | `a + b`   |
| `-`      | Subtraction    | `a - b`   |
| `*`      | Multiplication | `a * b`   |
| `/`      | Division       | `a / b`   |
| `%`      | Modulo         | `a % b`   |

### Important: Integer Division
```cpp
// C++:
int result = 7 / 3;        // result = 2 (truncated)
double exact = 7.0 / 3.0;  // exact = 2.333...
```
```typescript
// TypeScript:
let result = 7 / 3;                 // result = 2.333... (always decimal)
let truncated = Math.floor(7 / 3);  // truncated = 2
```

### Logical Operators

| Operator | Meaning        | Example        |
|----------|----------------|----------------|
| `&&`     | Logical AND    | `a && b`       |
| `\|\|`   | Logical OR     | `a \|\| b`     |
| `!`      | Logical NOT    | `!a`           |

### Short-Circuit Evaluation

Both C++ and TypeScript use short-circuit evaluation:
```cpp
// If 'a' is false, 'b' is never evaluated
if (a && b) { /* ... */ }

// If 'a' is true, 'b' is never evaluated  
if (a || b) { /* ... */ }
```

**Practical example:**
```cpp
int x = 0;
if (x != 0 && 10/x > 5) {  // Safe: division only happens if x != 0
    cout << "Large ratio" << endl;
}
```

- **Exponentiation operator** (use `pow()` function from `<cmath>`)


## Summary Points

- Control structures are nearly identical to TypeScript/JavaScript
- **Always use curly braces** - prevents hard-to-find bugs
- Integer division behaves differently - C++ truncates, TypeScript gives decimals
- Loop control statements work the same - `break`, `continue`, `return`
- Most operators are identical between languages
- Short-circuit evaluation works in both languages
- Be consistent with brace placement style
- Use increment/decrement operators safely - avoid combining with other operations
