## Core Concept: Streams Are Universal

### The Big Idea

In C++, **keyboard, screen, and files are all streams**. Same syntax works for all:
```cpp
// Reading from keyboard:
cin >> number;
getline(cin, line);

// Reading from file (IDENTICAL syntax):
file >> number;
getline(file, line);
```

This unified approach makes it easy to switch between different input sources!

## TypeScript vs C++ Approach

### TypeScript - Load Everything at Once
```typescript
import { readFileSync } from 'fs';

// Read entire file:
const content = readFileSync('data.txt', 'utf8');
const lines = content.split('\n');

// Process all data:
let sum = 0;
for (const line of lines) {
    sum += parseInt(line);
}
```

### C++ - Stream Processing
```cpp
#include <fstream>

// Read line by line:
ifstream file("data.txt");
string line;
while (getline(file, line)) {
    sum += stoi(line);  // Process as you read
}
```

**Key difference:** C++ processes data as it reads, TypeScript typically loads everything first.

## How Type Recognition Works

### Key Insight: Variable Type Determines Conversion

File contains: `"123 hello 456 world"`
```cpp
ifstream file("data.txt");

int first;      // Variable says: "convert to number"
string second;  // Variable says: "keep as text"  
int third;      // Variable says: "convert to number"
string fourth;  // Variable says: "keep as text"

file >> first;   // Reads "123" → converts to int 123
file >> second;  // Reads "hello" → keeps as string "hello"
file >> third;   // Reads "456" → converts to int 456
file >> fourth;  // Reads "world" → keeps as string "world"
```

The `>>` operator automatically converts based on the variable's type! This is similar to how [variables work with `cin`](2025/Autumn/COMP-CS-110-Programming-2/Week-1/1.2-Variables-and-Typing.md).

### What Happens on Conversion Failure

File contains: `"hello 123"`
```cpp
int number;
file >> number;  // Tries to convert "hello" to int
                 // FAILS! file.fail() becomes true
                 // number gets garbage value
```

**Important:** Always check if operations succeeded!

## File Position Tracking

### Internal Cursor Concept

C++ maintains an invisible "cursor" that remembers current position:

File: `"Line 1\nLine 2\nLine 3\n"`
```cpp
ifstream file("data.txt");
string line;

getline(file, line);  // Reads "Line 1", cursor moves to start of "Line 2"
getline(file, line);  // Reads "Line 2", cursor moves to start of "Line 3"
getline(file, line);  // Reads "Line 3", cursor moves to end of file
```

### Mixing `>>` and `getline()`

File:
```
123 apple
456 banana
```
```cpp
int num;
string word;
string fullLine;

file >> num;              // Reads "123", cursor stops BEFORE space
file >> word;             // Reads "apple", cursor stops BEFORE \n

getline(file, fullLine);  // Reads empty string (just the \n)
getline(file, fullLine);  // Now reads "456 banana"
```

**Problem:** `>>` leaves the newline character in the stream, so the next `getline()` reads it as an empty line.

**Solution:** Use `file.ignore()` to skip the newline:
```cpp
file >> num;
file.ignore();  // Skip the newline
getline(file, fullLine);  // Now reads next full line
```

## Stream Success Checking

### Streams as Boolean Values

In C++, stream objects can be used directly as conditions in `if` and `while` statements:
```cpp
ifstream file("data.txt");

// Stream used as boolean condition:
if (!file) {
    cout << "Error opening file!" << endl;
    return 1;
}

// Successful opening, continue...
```

### How Stream Operations Return Values

**Key insight:** Every stream operation returns a reference to the same stream object.
```cpp
// This line:
while (getline(file, line)) {
    // Process line
}

// Is equivalent to:
while (true) {
    getline(file, line);  // Returns reference to 'file'
    if (!file) break;     // Check if operation succeeded
    // Process line
}
```

### Implicit Type Conversion: Stream → bool

When a stream is used in boolean context, C++ automatically converts it:
- `true` = last operation was successful
- `false` = last operation failed (end of file, error, etc.)
```cpp
ifstream file("data.txt");
string line;

// Each getline() returns file reference
// Compiler converts file to bool
// true = successfully read line
// false = end of file or error

while (getline(file, line)) {
    cout << line << endl;
}
// Loop automatically stops at end of file
```

### Why This Pattern Works

Reading numbers until end of file:
```cpp
ifstream file("numbers.txt");
int number;

while (file >> number) {  // Returns file reference → converted to bool
    cout << number << endl;
}
// Stops when no more numbers to read
```

**Step by step:**
1. `file >> number` attempts to read a number
2. Returns reference to `file`
3. `while` converts `file` to bool
4. If read succeeded: `true` → continue loop
5. If end of file/error: `false` → exit loop

## Practical Examples

### Robust File Processing
```cpp
ifstream file("data.txt");

// Check if file opened
if (!file) {
    cerr << "Cannot open file!" << endl;
    return 1;
}

string line;
// Check each read operation
while (getline(file, line)) {
    if (line.empty()) continue;  // Skip empty lines
    cout << "Processing: " << line << endl;
}

// Loop automatically ended when file finished
cout << "File processing complete!" << endl;
```

### Mixed Data Types
```cpp
ifstream file("mixed.txt");
string word;
int number;

// Read word-number pairs until end of file
while (file >> word >> number) {  // Both operations must succeed
    cout << word << ": " << number << endl;
}
```

### Error vs End of File
```cpp
ifstream file("data.txt");
string line;

while (getline(file, line)) {
    // Process normally
}

// Check WHY loop ended:
if (file.eof()) {
    cout << "Reached end of file normally" << endl;
} else if (file.fail()) {
    cout << "Error occurred during reading" << endl;
}
```

## Basic File Operations

### Reading Files - Complete Example
```cpp
#include <fstream>
#include <iostream>
#include <string>
using namespace std;

int main() {
    // 1. Open file
    ifstream file("data.txt");
    
    // 2. Check if opened successfully  
    if (!file) {
        cout << "Error opening file!" << endl;
        return 1;
    }
    
    // 3. Read data
    string line;
    while (getline(file, line)) {
        cout << line << endl;
    }
    
    // 4. Close file (good practice)
    file.close();
    
    return 0;
}
```

### File Location Rules
```cpp
// Current working directory:
ifstream file("data.txt");

// Absolute path:
ifstream file("C:/Users/username/data.txt");     // Windows
ifstream file("/home/username/data.txt");        // Linux/Mac

// Relative path:
ifstream file("../data.txt");           // Parent directory
ifstream file("folder/data.txt");       // Subdirectory
```

**Note:** Use forward slashes `/` even on Windows in C++ (backslashes need escaping: `\\`).

## Reading Entire File into String

### Method 1: Line by Line (Preserving Line Breaks)
```cpp
ifstream file("data.txt");
string line;
string fullContent = "";

while (getline(file, line)) {
    fullContent += line + "\n";  // Add \n back (getline removes it)
}
```

### Method 2: Word by Word
```cpp
ifstream file("data.txt");
string word;
string fullContent = "";

while (file >> word) {
    fullContent += word + " ";  // Adds spaces between words
}
```

### Method 3: Character by Character
```cpp
ifstream file("data.txt");
char ch;
string fullContent = "";

while (file.get(ch)) {  // Read one character at a time
    fullContent += ch;
}
```

## Writing Files

### Basic Writing
```cpp
#include <fstream>

ofstream file("output.txt");

if (!file) {
    cout << "Error creating file!" << endl;
    return 1;
}

file << "Hello World" << endl;
file << "Number: " << 42 << endl;

file.close();  // Ensures data is saved to disk
```

### Appending to Files
```cpp
ofstream file("output.txt", ios::app);  // Append mode
file << "This will be added to end" << endl;
```

**File modes:**
- Default: Overwrites existing file
- `ios::app`: Appends to end of existing file
- `ios::trunc`: Truncates file if it exists (same as default)
- `ios::ate`: Opens at end of file but can write anywhere

## Common Patterns and Pitfalls

### Reading Numbers from File

File: `"10 20 30"`
```cpp
ifstream file("numbers.txt");
int sum = 0;
int number;

while (file >> number) {  // Reads until end of file
    sum += number;
}

cout << "Sum: " << sum << endl;  // Sum: 60
```

### Processing CSV-like Data

File: `"John,25,Engineer\nMary,30,Doctor"`
```cpp
ifstream file("people.txt");
string line;

while (getline(file, line)) {
    // Replace commas with spaces for easier parsing
    for (char& c : line) {
        if (c == ',') c = ' ';
    }
    
    // Now parse like normal
    istringstream iss(line);
    string name, job;
    int age;
    iss >> name >> age >> job;
    
    cout << name << " is " << age << " years old" << endl;
}
```

### Error Handling
```cpp
ifstream file("data.txt");

if (!file) {
    cerr << "Cannot open file!" << endl;
    return 1;
}

int number;
while (file >> number) {
    if (file.fail()) {
        cerr << "Error reading number!" << endl;
        file.clear();  // Clear error flag
        string badInput;
        file >> badInput;  // Skip bad input
        continue;
    }
    cout << "Read: " << number << endl;
}
```

## Summary Points

- **Streams are universal** - same syntax for keyboard, screen, and files
- **Variable type determines conversion** - not the file content ([see Variables and Typing](2025/Autumn/COMP-CS-110-Programming-2/Week-1/1.2-Variables-and-Typing.md))
- **Position tracking** - C++ remembers where you stopped reading
- Include `<fstream>` for file operations
- Always check if file opened with `if (!file)`
- `ifstream` = read only, `ofstream` = write only
- Files searched in current directory unless path specified
- Close files with `file.close()` for good practice
- `getline()` removes `\n` - add it back if needed
- Mix `>>` and `getline()` carefully - cursor positioning matters
- Use `file.ignore()` after `>>` before `getline()`

## Best Practices
```cpp
// Always check file opened
ifstream file("data.txt");
if (!file) {
    cerr << "Error: Cannot open file!" << endl;
    return 1;
}

// Use auto for readability
auto pos = line.find("keyword");

// Close files explicitly
file.close();

// Use references in loops to avoid copies
for (const auto& line : lines) {
    // process line
}
```

## Key Takeaways

1. **Stream abstraction is powerful** - same code for different sources
2. **Type safety helps** - compiler prevents type mismatches
3. **Position tracking is automatic** - no manual index management
4. **Error checking is essential** - always verify operations succeeded
5. **Streams handle buffering** - efficient even for large files
6. **Close files properly** - ensures data is written to disk

The stream concept in C++ makes file I/O intuitive once you understand that files are just another type of input/output source, treated the same way as the console.
