## Program Comparison: TypeScript vs C++

### TypeScript Version (Node.js with readline)
```typescript
import * as readline from 'readline';

const rl = readline.createInterface({
    input: process.stdin,
    output: process.stdout
});

function main(): void {
    rl.question("Input your name: ", (name: string) => {
        rl.question("Input your age: ", (ageInput: string) => {
            const age: number = parseInt(ageInput);
            console.log("Nice to meet you", name, age);
            console.log("After", 50 - age, "years you'll be 50.");
            rl.close();
        });
    });
}

main();
```

### C++ Version
```cpp
#include <iostream>
#include <string>
using namespace std;

int main() {
    string name = "";
    cout << "Input your name: ";
    getline(cin, name);
    
    int age = 0;
    cout << "Input your age: ";
    cin >> age;
    
    cout << "Nice to meet you " << name << " " << age << endl;
    cout << "After " << 50 - age << " years you'll be 50." << endl;
}
```

## Key Differences Between TypeScript and C++

### Program Length

C++ programs are often longer than similarly functioning TypeScript programs. More explicit declarations and setup required in C++.

### Variable Declaration and Usage

**TypeScript:** Can start using a variable by declaring it with `let`, `const`, or `var`. TypeScript enforces strict typing at compile time.

**C++:** A variable must **always be declared** before it can be used. Declaration tells the compiler the variable name and what type of information can be stored in it.

### Variable and Function Names

**TypeScript:** Variable and function names can contain Unicode characters including international letters

**C++:** Variable and function names must consist of:
- ASCII letters (a-z, A-Z)
- Digits (0-9)
- Underscore (_)
- **First character must be a letter**

**Note:** In strings, international letters are accepted in C++ but can be problematic in some situations.

### String Handling

**TypeScript:** Strings are a primitive type built into the language

**C++:** String data type is not part of the core language - it's implemented as a library. Must include `#include <string>` to use strings.

### Output Formatting

**TypeScript:** `console.log()` automatically adds spaces between values and newline at the end

**C++:** `cout` doesn't automatically add spaces between values or newlines. Must manually add `endl` for newlines.

## Input/Output Operations

### C++ Input/Output

C++ uses `cin` and `cout` for keyboard and screen operations:

**Reading methods in C++:**
```cpp
getline(cin, variable)  // For reading complete lines including spaces
cin >> variable         // For reading single values (stops at whitespace)
```

### Input Function Differences

**TypeScript:** Uses readline interface in Node.js for console input (asynchronous with callbacks)

**C++:** `getline()` takes two parameters:
1. Input stream (always `cin` in basic programs)
2. Variable where input will be stored

**Note:** `getline()` return value cannot be assigned to a string.

**Key difference:** TypeScript readline uses callbacks/async patterns, while C++ input is synchronous.

### Input Operator Behavior

`cin >>` behavior:
- Skips all empty characters including line breaks
- Reads until user gives visible characters
- Different from TypeScript where input is typically handled line by line

## Variables in C++

### Variable Definition Components

A variable definition contains three parts:
1. **Type** of the variable (mandatory)
2. **Name** of the variable (mandatory)
3. **Initialization** (optional but recommended)

### Variable Declaration Examples

**Without initialization:**
```cpp
int age;
double temperature;
string name;
```

**With initialization:**
```cpp
int age = 21;
double temperature = 16.7;
string name = "John";
```

**TypeScript equivalent:**
```typescript
// Without initialization
let age: number;
let temperature: number;
let name: string;

// With initialization
let age: number = 21;
let temperature: number = 16.7;
let name: string = "John";

// Type inference (TypeScript feature)
let age = 21;            // inferred as number
let temperature = 16.7;  // inferred as number
let name = "John";       // inferred as string
```

### Uninitialized Variables

**Problem:**
```cpp
int age;
double temperature;
// At this point both variables have undetermined values

age = 21;
cin >> temperature;
// Now both variables have determined values
```

**TypeScript comparison:**
```typescript
let age: number;
let temperature: number;
// TypeScript will warn about using these before assignment
```

**⚠️ Important Warning:** Uninitialized variables may produce programming errors that are very difficult to trace. **Always initialize variables in definition** for good programming style.

### Type Strictness

C++ is strict about variable types: **You can only store values of the same type as the variable's declared type.**

### Scope of a Variable

Local variables are defined inside a block (a pair of curly brackets `{}`) and can be used from the point of definition all the way to the closing bracket of the block:

**C++ example:**
```cpp
int main() {
    int guests = 0;
    while (guests < 100) {
        int free_seats = 100 - guests;
        // ... lines removed ...
        // This is the last point where variable free_seats can be used.
    }
    // ... lines removed ...
    // This is the last point where variable guests can be used.
}
```

**TypeScript equivalent:**
```typescript
function main(): void {
    let guests: number = 0;
    while (guests < 100) {
        let free_seats: number = 100 - guests;
        // ... lines removed ...
        // This is the last point where variable free_seats can be used.
    }
    // ... lines removed ...
    // This is the last point where variable guests can be used.
}
```

## Data Types

### Basic C++ Data Types

The data types in C++ for simple programs:
- `int` - integers
- `double` - decimal numbers (equivalent to TypeScript's `number`)
- `bool` - boolean values
- `string` - text strings
- `char` - single characters (unique to C++)

**C++ char example:**
```cpp
char gender = 'F'; // F for female
```

**TypeScript comparison:**
```typescript
// TypeScript doesn't have separate char type
let gender: string = 'F';          // Single character as string
let gender: 'F' | 'M' = 'F';       // Using literal types
```

## Literals and Constants

### Literals

A **literal** is a nameless constant value written directly in code:

**Examples:**
- `42` - integer literal
- `1.4142` - double literal
- `'x'` - character literal (C++ only)
- `"text"` - string literal
- `true` - boolean literal

### Quote Differences Between TypeScript and C++

**TypeScript:**
```typescript
let single = 'Hello';   // Same result
let double = "Hello";   // Same result - no difference
```

**C++:**
```cpp
string text = "Hello";  // ✅ String literals use double quotes
char letter = 'H';      // ✅ Character literals use single quotes

// Important difference:
char letter = 'X';      // ✅ Single character
string word = "X";      // ✅ String containing one character
char wrong = "X";       // ❌ ERROR! Cannot assign string to char
```

### Constants

Constants are variables whose value cannot be changed after initialization:

**C++ constants:**
```cpp
const double PI = 3.14;
const int LOTTO_BALLS = 7;

// Trying to change produces error:
PI = 3.141592653589793; // ERROR
```

**TypeScript constants:**
```typescript
const PI: number = 3.14;
const LOTTO_BALLS: number = 7;

// Trying to change produces error:
PI = 3.141592653589793; // ERROR - TypeScript also prevents this
```

### Constant Naming Convention

- Use `ALL_CAPITAL_LETTERS`
- Replace spaces with underscores `_`
- Must be initialized with declaration
- Makes code more readable and maintainable

## Dynamic vs Static Typing

### Dynamic Typing Example (JavaScript behavior)
```javascript
// This would work in plain JavaScript:
function main() {
    console.log("Start");
    let var_1 = 5.3;
    let var_2 = 7.1;
    console.log(var_1 + var_2);     // 12.4
    var_2 = "Hello";                // Variable type changes!
    console.log("Midpoint");
    console.log(var_1 + var_2);     // "5.3Hello" - unexpected result!
    console.log("End");
}
```

### Static Typing in TypeScript
```typescript
function main(): void {
    console.log("Start");
    let var_1: number = 5.3;
    let var_2: number = 7.1;
    console.log(var_1 + var_2);     // 12.4
    var_2 = "Hello";                // ❌ ERROR! TypeScript prevents this
    console.log("Midpoint");
    console.log(var_1 + var_2);     // Never reaches here
    console.log("End");
}
```

### Static Typing in C++
```cpp
#include <iostream>
#include <string>
using namespace std;

int main() {
    cout << "Start" << endl;
    double var_1 = 5.3;
    double var_2 = 7.1;
    cout << var_1 + var_2 << endl;
    string var_3 = "Hello";         // New variable required
    cout << "Midpoint" << endl;
    cout << var_1 + var_3 << endl;  // ❌ ERROR! Cannot add double + string
    cout << "End" << endl;
}
```

### Key Differences Summary

**Dynamic Typing (JavaScript):**
- Variables can change type during execution
- Errors discovered at runtime
- More flexible but potentially dangerous

**Static Typing (TypeScript/C++):**
- Variables have permanent type
- Errors caught at compile time
- Less flexible but safer and more predictable

## Type Conversion

### Implicit Type Conversion

Compiler automatically converts compatible types:

**C++ examples:**
```cpp
float f = 0.123;
double d = f;        // float → double (automatic)
double d = 3;        // int → double (automatic)
char ch = 113;       // int → char (ch becomes 'q', ASCII 113)
```

**TypeScript comparison:**
```typescript
let f: number = 0.123;
let d: number = f;                         // No conversion needed (both are 'number')
let d: number = 3;                         // No conversion needed
let ch: string = String.fromCharCode(113); // Manual conversion to get 'q'
```

### Explicit Type Conversion

Programmer manually specifies type conversion using `static_cast`:

**C++ explicit conversion:**
```cpp
int i = 0;
unsigned int ui = 0;

// With warning:
if (ui == i) { /* ... */ }  // Compiler warning

// Explicit conversion (no warning):
if (ui == static_cast<unsigned int>(i)) { /* ... */ }
```

**Character to ASCII example:**
```cpp
cout << "Input a character: ";
char ch = ' ';
cin >> ch;
int ascii_value = static_cast<int>(ch);
cout << "ASCII value of " << ch << " is " << ascii_value << endl;
```

**TypeScript equivalent:**
```typescript
const ch: string = 'A';                        // Get character
const ascii_value: number = ch.charCodeAt(0);  // Get ASCII value
console.log(`ASCII value of ${ch} is ${ascii_value}`);
```

## Summary Points

- C++ requires explicit type declarations - unlike TypeScript's type inference
- C++ needs library imports - strings require `#include <string>`
- C++ input/output is more manual - no automatic spacing or newlines
- **Always initialize variables** - prevents unpredictable behavior
- Static typing in both languages - type errors caught at compile time
- Scope rules are similar - variables live within their block
- C++ has `char` type - TypeScript uses strings for single characters
- Constants work similarly - both prevent value changes after initialization
- Type conversion is more explicit in C++ - TypeScript handles most conversions automatically
