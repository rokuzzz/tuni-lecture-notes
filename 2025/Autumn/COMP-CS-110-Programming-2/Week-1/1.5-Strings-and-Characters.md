## String Mutability: Key Difference

### TypeScript - Immutable Strings
```typescript
function main(): void {
    let text = "abcdefg";
    console.log(text[3]);     // Prints 'd'
    
    // text[3] = "X";         // ❌ Error! Strings are immutable
    
    // Must create new string:
    text = text.slice(0, 3) + "X" + text.slice(4);
    console.log(text);        // Prints "abcXefg"
}
```

### C++ - Mutable Strings
```cpp
#include <iostream>
#include <string>   // Note: string is a library type in C++
using namespace std;

int main() {
    string text = "abcdefg";
    cout << text.at(3) << endl;  // Prints 'd'
    
    text.at(3) = 'X';            // ✅ Direct modification! Note: char 'X'
    cout << text << endl;        // Prints "abcXefg"
}
```

## Key Differences: char vs string

### Character Types
```cpp
// C++:
char letter = 'X';        // Single character (char type)
string word = "X";        // String containing one character
string text = "Hello";    // String of multiple characters

text.at(0) = 'H';         // ✅ Must use char 'H', not string "H"
```

### TypeScript Comparison
```typescript
// TypeScript - everything is string:
let letter: string = 'X';     // Still a string
let word: string = "X";       // Same as above  
let text: string = "Hello";   // String

text = text[0].toUpperCase() + text.slice(1); // Must recreate string
```

**Critical Rule:** In C++, single characters use single quotes `'X'` and have type `char`. Strings use double quotes `"X"` and have type `string`.

## Essential String Methods

### Length and Access
```cpp
string text = "One string to rule them all...";

// Get length:
string::size_type len = text.length();

// Access characters:
char first = text.at(0);          // Get character at index 0
text.at(4) = 'S';                 // Set character at index 4
```

### TypeScript Equivalent
```typescript
let text = "One string to rule them all...";

// Get length:
let len: number = text.length;    // Property, not method

// Access characters (read-only):
let first: string = text[0];      // Or text.charAt(0)
// text[4] = 'S';                 // ❌ Cannot modify
```

### Substring Operations
```cpp
string text = "One string to rule them all...";

// Extract substring:
string part1 = text.substr(4, 14);     // From index 4, length 14
string part2 = text.substr(4);         // From index 4 to end

// Replace part:
text.replace(4, 6, "thing");           // Replace 6 chars from index 4
```

### TypeScript Equivalent
```typescript
let text = "One string to rule them all...";

// Extract substring:
let part1: string = text.substring(4, 18);  // From 4 to 18 (not length!)
let part2: string = text.substring(4);      // From 4 to end

// Replace part:
text = text.slice(0, 4) + "thing" + text.slice(10);  // Manual reconstruction
```

### Search Operations
```cpp
string name = "Hello";
string::size_type pos = name.find("ell");

if (pos == string::npos) {
    cout << "Not found!" << endl;
} else {
    cout << "Found at position: " << pos << endl;
}
```

### TypeScript Equivalent
```typescript
let name = "Hello";
let pos: number = name.indexOf("ell");

if (pos === -1) {
    console.log("Not found!");
} else {
    console.log("Found at position:", pos);
}
```

## Important: string::size_type and string::npos

### Why Not Just int?
```cpp
// ❌ Works but not recommended:
int length = text.length();

// ✅ Correct and safe:
string::size_type length = text.length();

auto length2 = text.length();  // Easier alternative
```

**Reason:** `string::size_type` is an unsigned type that's guaranteed to hold the size of any string. Using `int` might cause issues with very large strings or when comparing with `string::npos`.

### Special Value: string::npos
```cpp
string::size_type pos = text.find("xyz");

if (pos == string::npos) {
    // Not found - npos means "no position"
}
```

**TypeScript uses -1 instead:**
```typescript
let pos = text.indexOf("xyz");
if (pos === -1) {
    // Not found
}
```

## Useful String Operations

### Modification Methods
```cpp
string text = "Hello World";

// Erase characters:
text.erase(5, 6);        // Remove " World" (from index 5, length 6)
text.erase(5);           // Remove everything from index 5 onwards

// Insert text:
text.insert(5, " C++");  // Insert " C++" at position 5

// Find from end:
string::size_type pos = text.rfind("l");  // Find last occurrence of "l"
```

### String Operators
```cpp
string str1 = "Hello";
string str2 = "World";

// Concatenation:
string result = str1 + " " + str2;    // "Hello World"
str1 += " ";                          // str1 becomes "Hello "
str1 += str2;                         // str1 becomes "Hello World"

// Comparison:
if (str1 == str2) { /* equal */ }
if (str1 < str2) { /* lexicographical order */ }
```

### TypeScript Comparison
```typescript
let str1 = "Hello";
let str2 = "World";

// Concatenation (similar):
let result = str1 + " " + str2;       // "Hello World"
str1 += " ";                          // str1 becomes "Hello "
str1 += str2;                         // str1 becomes "Hello World"

// Comparison (similar):
if (str1 === str2) { /* equal */ }
if (str1 < str2) { /* lexicographical order */ }
```

## Conversion Functions

### String to Number
```cpp
#include <string>

string numText = "123";
int number = stoi(numText);           // String to int

string floatText = "123.456";
double decimal = stod(floatText);     // String to double
```

### TypeScript Equivalent
```typescript
let numText = "123";
let number: number = parseInt(numText);        // String to int
let number2: number = Number(numText);         // Alternative

let floatText = "123.456";
let decimal: number = parseFloat(floatText);   // String to float
let decimal2: number = Number(floatText);      // Alternative
```

### Warning: Partial Conversion
```cpp
// C++ problem:
int result = stoi("123abc");    // Returns 123 (ignores "abc"!)
// Better error checking needed
```
```typescript
// TypeScript:
let result = parseInt("123abc");    // Also returns 123
let result2 = Number("123abc");     // Returns NaN (safer)
```

## Characters as Numbers

### ASCII Values
```cpp
char ch = 'A';
int ascii = static_cast<int>(ch);   // ASCII value of 'A' is 65

// Character arithmetic:
for (char letter = 'a'; letter <= 'z'; ++letter) {
    cout << letter;                 // Prints: abcdefghijklmnopqrstuvwxyz
}
```

### TypeScript Equivalent
```typescript
let ch = 'A';
let ascii: number = ch.charCodeAt(0);   // ASCII value of 'A' is 65

// Character iteration:
for (let i = 'a'.charCodeAt(0); i <= 'z'.charCodeAt(0); i++) {
    console.log(String.fromCharCode(i));
}
```

## Character Testing (cctype library)
```cpp
#include <cctype>

char ch = 'A';

bool isLower = islower(ch);        // false
bool isUpper = isupper(ch);        // true  
bool isDigit = isdigit(ch);        // false

char lower = tolower(ch);          // 'a'
char upper = toupper('a');         // 'A'
```

### TypeScript Equivalent
```typescript
let ch = 'A';

// No direct equivalents, use string methods:
let isLower = ch === ch.toLowerCase() && ch !== ch.toUpperCase();
let isUpper = ch === ch.toUpperCase() && ch !== ch.toLowerCase();
let isDigit = /\d/.test(ch);

let lower = ch.toLowerCase();      // 'a'
let upper = ch.toUpperCase();      // 'A'
```

## Common Character Functions

| Function      | Description                    | Example               |
|---------------|--------------------------------|-----------------------|
| `isalpha(ch)` | Is alphabetic character?       | `isalpha('A')` → true |
| `isdigit(ch)` | Is digit 0-9?                  | `isdigit('5')` → true |
| `isalnum(ch)` | Is alphanumeric?               | `isalnum('?')` → false|
| `isspace(ch)` | Is whitespace?                 | `isspace(' ')` → true |
| `ispunct(ch)` | Is punctuation?                | `ispunct('!')` → true |
| `toupper(ch)` | Convert to uppercase           | `toupper('a')` → 'A'  |
| `tolower(ch)` | Convert to lowercase           | `tolower('A')` → 'a'  |

## Common Patterns

### Filter alphanumeric only:
```cpp
string text = "hello123!@#";
string result = "";
for (char c : text) {
    if (isalnum(c)) {
        result += c;
    }
}
// result = "hello123"
```

### Convert to uppercase:
```cpp
string text = "hello world";
for (char& c : text) {  // Note the & - modifies original
    c = toupper(c);
}
// text = "HELLO WORLD"
```

### Check if all letters:
```cpp
string text = "HelloWorld";
bool allLetters = true;
for (char c : text) {
    if (!isalpha(c)) {
        allLetters = false;
        break;
    }
}
```

### Remove non-digits:
```cpp
string text = "abc123def456";
string digits = "";
for (char c : text) {
    if (isdigit(c)) {
        digits += c;
    }
}
// digits = "123456"
```

## Summary: Key Differences

| Feature               | C++                           | TypeScript                |
|----------------------|-------------------------------|---------------------------|
| **Mutability**       | Strings are mutable           | Strings are immutable     |
| **Character type**   | `char` with single quotes     | Just strings              |
| **Access syntax**    | `text.at(i)` or `text[i]`     | `text[i]` or `text.charAt(i)` |
| **Modification**     | Direct: `text.at(i) = 'X'`    | Must recreate string      |
| **Not found value**  | `string::npos`                | `-1`                      |
| **Size type**        | `string::size_type`           | `number`                  |
| **Character testing**| `<cctype>` functions          | String methods/regex      |

## Best Practices

### Use `auto` for string operations:
```cpp
auto pos = text.find("abc");  // Easier than string::size_type
```

### Always check for `string::npos`:
```cpp
if (pos != string::npos) { /* found */ }
```

### Remember `char` vs `string`:
```cpp
text.at(0) = 'X';    // char
text += "suffix";    // string
```

### Include necessary headers:
```cpp
#include <string>    // For string class
#include <cctype>    // For character testing
```

## Key Takeaways

1. **C++ strings are mutable** - can modify characters directly
2. **`char` and `string` are different** - single quotes vs double quotes
3. **Use `string::npos` for "not found"** - not `-1` like TypeScript
4. **`string::size_type` is the correct type** - not `int`
5. **Include `<cctype>` for character functions** - very useful for text processing
6. **Characters can be treated as numbers** - enables arithmetic operations
7. **Always include `<string>`** - string is a library type, not built-in
