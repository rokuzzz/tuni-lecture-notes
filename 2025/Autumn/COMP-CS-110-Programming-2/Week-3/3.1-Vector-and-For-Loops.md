## STL - Standard Template Library

STL consists of three logical components:

1. **Containers** - data structures (vector, set, map)
2. **Iterators** - "bookmarks" for navigating through containers
3. **Algorithms** - ready-made functions for data operations

STL provides a powerful toolkit for working with data collections, similar to modern libraries in other languages.

## Vector - Dynamic Array

### Core Characteristics

Vector resembles arrays in TypeScript, but with one important difference - **all elements must be of the same type**.
```cpp
#include <vector>

vector<int> scores;           // Equivalent to: number[] in TypeScript
vector<string> names;         // Equivalent to: string[] in TypeScript
```

### Essential Operations

**Adding and removing elements:**
```cpp
scores.push_back(21);         // Add to end
scores.pop_back();            // Remove last element
```

**Element access:**
```cpp
scores.at(0);                 // Safe access with bounds checking
scores[0];                    // Fast access without checking
scores.front();               // First element  
scores.back();                // Last element
```

**Size and validation:**
```cpp
scores.size();                // Number of elements

if (scores.size() != 0) {     // Check if not empty
    scores.pop_back();
}
```

### TypeScript Comparison
```typescript
// TypeScript
const scores: number[] = [];
scores.push(21);              // Same as C++
scores.pop();                 // Removes and returns element
console.log(scores.length);   // Array size
```

TypeScript arrays are more flexible - they can contain different types, while C++ vector is strictly typed.

## Vector Initialization

### Different Creation Methods
```cpp
vector<int> numbersA(20);                   // 20 elements, uninitialized
vector<double> numbersB(10, 5.3);           // 10 elements with value 5.3
vector<string> namesC = {"Anna", "Peter"};  // Initialization list
```

### Function Parameters
```cpp
void function1(vector<double> data);        // By value (copying)
void function2(vector<double>& data);       // By reference (modifiable)
void function3(const vector<double>& data); // By reference (read-only)
```

For large containers, use `const&` for efficiency - avoid unnecessary data copying. See [parameter passing](2.3-Parameter-Passing.md) for details.

## For Loops in C++

### Range-based for (Modern Approach)
```cpp
vector<int> numbers = {1, 2, 3, 4, 5};

// Read-only access
for (int element : numbers) {
    cout << element << endl;
}

// Modifying elements
for (int& element : numbers) {
    element *= 2;                    // Double each element
}

// Type deduction
for (auto element : numbers) {       // Compiler determines type
    cout << element << endl;
}
```

### Traditional for with Indices
```cpp
for (size_t i = 0; i < numbers.size(); ++i) {
    cout << numbers.at(i) << endl;
}

// General structure
for (initialization; condition; increment) {
    // loop body
}
```

### TypeScript Comparison
```typescript
// TypeScript - several options
const numbers = [1, 2, 3, 4, 5];

// for...of (equivalent to range-based for)
for (const element of numbers) {
    console.log(element);
}

// Traditional loop
for (let i = 0; i < numbers.length; i++) {
    console.log(numbers[i]);
}

// forEach
numbers.forEach(element => console.log(element));
```

## Two-Dimensional Vectors

### Declaration and Usage
```cpp
vector<vector<int>> matrix;           // 2D array

using Board = vector<vector<int>>;    // Alias for readability
Board gameBoard;
```

Two-dimensional vectors are useful for representing tables, game boards, or matrices. The TypeScript equivalent would be `number[][]`.

### Element Access
```cpp
matrix[row][col] = value;             // Set value
int value = matrix[row][col];         // Get value
```

## Key Vector Features

### Access Safety

- `at(index)` - checks bounds, throws exception on error
- `[index]` - fast access without checks, can cause errors

**When to use which:**
```cpp
// Use at() when safety is priority
if (index < vec.size()) {
    cout << vec.at(index) << endl;
}

// Use [] when performance is critical and bounds are guaranteed
for (size_t i = 0; i < vec.size(); ++i) {
    cout << vec[i] << endl;  // i is always valid here
}
```

### Performance

Vector is optimal when:
- Index-based access is needed
- Adding elements to the end
- Sequential element traversal

Vector is less efficient for:
- Frequent insertions in the middle
- Searching for specific elements

## Practical Guidelines

### Choosing Loop Type

**Range-based for** for simple traversal of all elements:
```cpp
for (const auto& element : vec) {
    cout << element << endl;
}
```

**Traditional for** when index control is needed:
```cpp
for (size_t i = 0; i < vec.size(); ++i) {
    cout << "Element " << i << ": " << vec[i] << endl;
}
```

**Use references** (`auto&`) when modifying elements:
```cpp
for (auto& element : vec) {
    element *= 2;  // Modifies original
}
```

### Function Parameters
```cpp
// Reading data
void process(const vector<int>& data) {
    // Can't modify, no copying
}

// Modifying data
void modify(vector<int>& data) {
    // Can modify original
}

// Avoid pass-by-value for large containers
void bad_practice(vector<int> data) {  // ❌ Creates expensive copy
    // ...
}
```

## Common Patterns

### Finding Elements
```cpp
vector<int> numbers = {10, 20, 30, 40};

// Linear search
bool found = false;
for (const auto& num : numbers) {
    if (num == 30) {
        found = true;
        break;
    }
}
```

### Filtering
```cpp
vector<int> positive_only;
for (int num : numbers) {
    if (num > 0) {
        positive_only.push_back(num);
    }
}
```

### Transformation
```cpp
vector<int> doubled;
for (int num : numbers) {
    doubled.push_back(num * 2);
}
```

## Summary

- **Vector is C++'s dynamic array** - similar to TypeScript arrays but strictly typed
- **Two access methods** - `at()` for safety, `[]` for speed
- **Range-based for** - modern, clean syntax for iteration
- **Traditional for** - needed when working with indices
- **Use `const&` for large objects** - avoid copying in function parameters
- **Type deduction with `auto`** - compiler figures out the type
- **Strictly typed** - all elements must be the same type

Vector represents a powerful and flexible tool for working with data sequences, combining ease of use with high performance.
