## Graphs

### What is a Graph?

A **directed graph (digraph)** G is a pair (V, E):

- **V** = vertex set (nodes)
- **E** = edge set (ordered pairs of vertices)

An element of E is called an **edge** (or arc/link) and is an **ordered pair (a,b)** of vertices.

**For an ordered pair:** (a,b) ≠ (b,a)

**Synonyms:**

- vertex = node
- edge = arc = link

### Example Graph

```
V = {a, b, c, d, e, f}
E = {(b,d), (d,c), (c,b), (c,d), (c,a), (c,e), (e,a), (e,e), (e,f)}
```

### Graph Terminology

**For directed graphs (digraphs):**

- If edge (a,b) exists → **b is adjacent to a**
- If edge (a,b) exists → **a is starting vertex**, **b is final vertex**
- **In-degree** of vertex a = number of edges entering a
- **Out-degree** of vertex a = number of edges leaving from a

**Example from graph above:**

|vertex|vertices adjacent to x|vertices to which x is adjacent|in-degree|out-degree|
|---|---|---|---|---|
|a|—|c, e|2|0|
|b|d|c|1|1|
|c|b, d, e, a|d|1|4|
|d|c|b, c|2|1|
|e|c, a, f|c, e|2|3|
|f|—|e|1|0|

**For undirected graphs:**

- Edge (a,b) = (b,a) (no direction)
- **Degree** of vertex a = number of vertices adjacent to a
- **Isolated vertex** = vertex with degree 0

**NOTE:** Multiple edges between same vertices are NOT allowed.

### Path Terminology

- **Path** of length k from vertex a₀ to vertex aₖ = ordered sequence ⟨a₀, a₁, a₂, ... aₖ⟩ where each edge (aᵢ, aᵢ₊₁) exists
- **Simple path** = path with no repeated vertices
- If path exists from a to b → **b is reachable from a**
- **Connected** (undirected graph) = every vertex reachable from every other
- **Strongly connected** (digraph) = every vertex reachable from every other
- **Cycle** = path where a₀ = aₖ
- **Simple cycle** = cycle where only first/last vertex repeats
- **Acyclic graph** = graph with no cycles

### Example Paths

```
From graph above:
Paths from b to a:
⟨b, c, a⟩                  length = 2
⟨b, d, c, e, a⟩            length = 4
⟨b, d, c, b, d, c, a⟩      length = 6

Simple paths: ⟨b, c, a⟩ and ⟨b, d, c, e, a⟩

Cycles in graph:
⟨b, d, c, b⟩              simple
⟨a, c, e, a⟩              simple
⟨a, c, b, d, c, e, a⟩     not simple (c repeats)
```

## Trees

### Undirected Trees

Each of the following **equivalent** definitions describes an undirected tree G = (V, E):

1. G is connected and acyclic
2. G is connected and |E| = |V| - 1
3. There is a unique simple path connecting every two vertices in G
4. G is acyclic, but adding any edge to E results in a graph with one cycle

### Example Classification

```
G₁: Contains cycle → NOT a tree
G₂: No path from d to e → NOT a tree
G₃: Connected and acyclic → IS A TREE ✅
```

### Rooted Trees

A **rooted tree** is a digraph (V, E) where:

- There is a unique simple path from one particular vertex (the **root** r) to any other vertex
- There is no path from any vertex to r

**NOTE:** Usually arrows omitted when drawing, root at top

### Example Classification

```
D₁: No vertex has path to all others → NOT rooted tree
D₂: Two paths from d to a → NOT rooted tree
D₃: Unique paths from d to all → IS ROOTED TREE (root = d) ✅
```

### Rooted Tree Terminology

Given a rooted tree with root r:

- If a is on the unique path from r to b → **a is ancestor of b**
- If a is ancestor of b → **b is descendant of a**
- **Subtree rooted at a** = rooted tree with a as root, includes all descendants of a
- If (a,b) is an edge → **a is b's parent**, **b is a's child**
- Vertices with same parent = **siblings**
- Vertex with no children = **leaf** (external vertex)
- Vertex with children = **internal vertex**
- **Depth** of vertex a = length of simple path from r to a
- **Height** of tree = largest depth of any vertex

### Example Analysis

```
Tree with root d:

       d (depth 0)
      / \
     b   c (depth 1)
    /   / \
   g   e   a (depth 2)
        \
         f (depth 3)

From path d → c → e → f:
- c is ancestor of f
- f is descendant of c
- c is e's parent
- e is c's child
- e and a are siblings
- Leaves: g, f, a (no children)
- Internal vertices: d, c, e (have children)
- Tree height: 3
```

## Binary Trees

### Definition

A **binary tree** is a rooted tree where every vertex has at most two children.

### Binary Tree Terminology

- **Empty tree** (null tree) = tree with no vertices
- Each child is either **left child** or **right child**
- When vertex has no left (right) child → left (right) child is **missing**
- If b is left (right) child of a → **left subtree (right subtree)** of a is subtree rooted at b
    - NOTE: Both left and right subtrees are also binary trees
- **Full binary tree** = each vertex has either two children or no children
- **Complete binary tree** = full binary tree where all leaves are at same depth

### Example Analysis

```
Tree structure:

       d (root)
      / \
     b   c
    /   / \
   g   e   a
        \
         f

Vertex table:
| vertex | left child | right child | parent |
|--------|------------|-------------|--------|
| a      | —          | —           | c      |
| b      | g          | —           | d      |
| c      | e          | a           | d      |
| d      | b          | c           | —      |
| e      | —          | f           | c      |
| f      | —          | —           | e      |
| g      | —          | —           | b      |

Left subtree of d:      Right subtree of d:
    b                        c
   /                        / \
  g                        e   a
                            \
                             f
```

### Binary Tree Classification Examples

**T₁:** b has only one child → NOT full binary tree

**T₂:** Full (all nodes have 0 or 2 children), but NOT complete (leaves b and e not at same depth)

**T₃:** Complete binary tree ✅ (full AND all leaves at same depth)

## Quick Reference

### Graph Notation

```
G = (V, E)
V = {vertices}
E = {(ordered pairs of vertices)}
```

### Graph Properties

- **Directed:** edges have direction (a,b) ≠ (b,a)
- **Undirected:** edges have no direction (a,b) = (b,a)
- **Adjacency:** relationship between connected vertices
- **Degree:** count of connections (in-degree + out-degree for directed)
- **Path:** sequence of connected vertices
- **Connected:** all vertices reachable from each other
- **Acyclic:** no cycles

### Tree Properties

- **Undirected tree:** connected + acyclic, |E| = |V| - 1
- **Rooted tree:** unique paths from root, hierarchical
- **Binary tree:** ≤ 2 children per vertex
- **Full binary tree:** 0 or 2 children per vertex
- **Complete binary tree:** full + all leaves at same depth

### Tree Relationships

```
Root (depth 0)
  ↓
Parent
  ↓
Child (sibling ←→ sibling)
  ↓
Descendant
  ↓
Leaf (no children)
```

### Key Formulas

- Tree edges: |E| = |V| - 1
- Depth = distance from root
- Height = maximum depth in tree

### Common Applications

- **Graphs:** social networks, maps, web links, task scheduling
- **Trees:** file systems, company hierarchy, decision trees, parsers, BST
